## 3. Streamlit 탭 동작 정리

- **`st.tabs`**: 모든 탭 블록이 **매 rerun마다 실행**됨. 보이는 탭만 다를 뿐, 코드는 전부 실행.
- **`st.radio` + `if selected_tab == "탭1":`**: 선택된 탭에 해당하는 블록만 실행.

대시보드는 이미 `st.radio` 패턴을 사용하므로 탭별 지연 로딩이 적용되어 있음.
